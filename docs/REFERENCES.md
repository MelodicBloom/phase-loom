# References and bounded decisions

These sources support design and architecture choices; they are not performance baselines measured on this machine.

| Evidence / method                                                                                                                                               | Action                                                                                              | Intended outcome                                                                                                                   |
| --------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------- |
| [SPACE TYPE GENERATOR](https://www.behance.net/gallery/69674423/SPACE-TYPE-GENERATOR-_vcylinder) demonstrates explicit geometric parameters and periodic waves. | Give aperture, phase and frequency pair distinct geometry roles; expose a finite clock.             | Each control has a visible, reproducible consequence.                                                                              |
| [Lusion on Awwwards](https://www.awwwards.com/sites/lusion) documents WebGL spatial interaction and a dominant scene.                                           | Use a single coherent sculpture with deliberate framing instead of a grid of unrelated effects.     | A strong visual focal point and a readable interaction model.                                                                      |
| [Superdesign's library](https://superdesign.dev/library) includes portal/reveal and editorial composition studies.                                              | Make opening the aperture the central physical-looking action; keep the inspector subordinate.      | Opening and alignment remain legible in stills as well as motion.                                                                  |
| [Three.js](https://threejs.org/) provides WebGL scene/lifecycle infrastructure.                                                                                 | Keep one indexed mesh and a small custom GLSL material; expose renderer readiness and disposal.     | Direct shader control without reimplementing a complete graphics engine.                                                           |
| [Storybook Code Panel](https://storybook.js.org/docs/writing-docs/code-panel) treats preview/source as related evidence.                                        | Import real adapter files into copy blocks and mount their runtimes.                                | Copy examples do not drift from live previews. This implementation is a custom catalogue, not an installed Storybook distribution. |
| [Ark UI](https://ark-ui.com/) and [Zag](https://www.zagjs.com/overview/introduction) demonstrate shared stateful behavior across framework bindings.            | Share a framework-independent core and Web Component renderer; keep React/Vue/Svelte wrappers thin. | The same state can be rendered in each supported framework.                                                                        |

No reference artwork, live shader source or site layout was copied. The material is an artistic conductor-inspired model and the inverse operation searches a structural descriptor; neither is claimed as measured physical optics.
